# 🚀 Online CV Portfolio - Amirhossein Bayani

A modern, visually stunning portfolio website built with Next.js 16 and Tailwind CSS 4. This CV showcases a Full Stack Software Developer's experience, skills, projects, and education in an attractive, interactive format.

### [Live Show](https://cv-online-indol.vercel.app/)

## ✨ Features

- **🎨 Modern Design**: Beautiful gradient backgrounds with animated blob effects
- **💎 Glass-morphism UI**: Semi-transparent cards with backdrop blur effects
- **🌈 Color-Coded Sections**: Each section has unique, vibrant color schemes
- **📱 Fully Responsive**: Mobile-first design that works on all screen sizes
- **🌗 Dark Mode Support**: Automatic dark mode with beautiful color transitions
- **✨ Smooth Animations**: Fade-in effects, hover transformations, and floating animations
- **🎯 Interactive Elements**: Hover effects on cards, buttons, and skill tags
- **♿ Accessible**: Semantic HTML and ARIA-compliant components
- **⚡ Performance Optimized**: Built with Next.js 16 for optimal performance

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) with TypeScript
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Language**: TypeScript
- **Font**: Geist Sans & Geist Mono from Google Fonts
- **Icons**: Custom SVG icons throughout

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v20 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## 📦 Build for Production

Create an optimized production build:

```bash
npm run build
npm start
# or
yarn build
yarn start
```

## 📁 Project Structure

```
my-cv-app/
├── app/
│   ├── globals.css          # Global styles and animations
│   ├── layout.tsx           # Root layout with fonts and metadata
│   └── page.tsx             # Main CV page component
├── public/                  # Static assets
├── next.config.ts           # Next.js configuration
├── tailwind.config.ts       # Tailwind CSS configuration
├── tsconfig.json            # TypeScript configuration
└── package.json             # Project dependencies
```

## 🎨 Customization

### Personal Information

Edit `app/page.tsx` to update:

- Name and title
- Contact information
- Professional summary
- Work experience
- Education
- Skills
- Projects

### Styling

Modify `app/globals.css` to customize:

- Color schemes
- Animations
- Gradients
- Hover effects

### Fonts

The project uses Geist fonts. To change fonts, edit `app/layout.tsx`.
